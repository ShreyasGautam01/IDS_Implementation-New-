# Manuscript claim-to-evidence map

**Snapshot:** 2026-11-04  
**Scope:** NF-UNSW-NB15-v3 temporal reliability experiment and its bounded supporting audits.

Use this map when drafting the manuscript. The evidence hierarchy is: regenerated per-seed metadata and predictions first, aggregate reports second, protocol/code for method definitions, and legacy manuscripts only for historical context. Do not use the legacy IEEE Random Forest paper's numbers as evidence for this study.
